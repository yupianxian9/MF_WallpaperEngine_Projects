## 一、仓库说明

该仓库仅仅是为了存放麻匪大佬的wallpaper engine壁纸项目源码文件，所有壁纸版权归`Hope麻匪`所有。

`Hope麻匪`B站主页地址：https://space.bilibili.com/111174060

## 二、项目源码文件使用说明

【文件夹】初级学习项目：
相对比较简单的壁纸制作

【文件夹】进阶高级项目：
多方位制作案例 相对较为复杂

压缩的项目文件
解压后的文件可以移植到 
此文件夹内 进行编辑制作学习
你的盘符位置:\SteamLibrary\steamapps\common\wallpaper_engine\projects\myprojects

比如：压缩包名字为 麻匪123  解压后得到麻匪123主项目文件夹 直接移植到指定文件夹内即可
移植正确位置案例 D:\SteamLibrary\steamapps\common\wallpaper_engine\projects\myprojects\麻匪123

【文件夹】SceneScript代码混淆还原备份：
少部分项目SceneScript代码 使用了混淆加密 
此文件夹里的内容 就是用来还原源代码内容的一些原项目文件 
可以根绝项目名字对照找回源代码
